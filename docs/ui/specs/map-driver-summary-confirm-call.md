# UI Spec — 地图点司机标记—行程摘要与确认后电话

## 1. 目标与约束

- **用户目标：** 乘客点地图司机标记后，快速看懂行程并决定是否确认同行；确认后才能打电话。
- **业务约束：**
  - 单小程序双模式（本 Spec 主路径为**乘客**；司机仅查看）。
  - **联系权非对称**：仅乘客确认后可取司机电话；司机无拨号入口。
  - 确认前不展示可用拨号；服务端鉴权不可削弱。
- **不在范围：** 管理端、支付、IM、轨迹、司机回拨乘客。

## 2. 入口与导航

| 从哪来 | 动作 | 到哪去 |
| --- | --- | --- |
| Tab「地图」乘客模式 | 点击车找人标记 | **行程摘要底栏**（本页浮层，不先整页跳转） |
| 摘要底栏 | 点「查看详情」或主区域 | 详情页 `detail?type=driver_trip&id=` |
| 详情页 | 确认同行成功 | 同页进入「可联系」态 |
| 详情页 | 拨打电话 | 系统拨号（真机） |
| Tab「地图」司机模式 | 点击人找车标记 | 摘要底栏（无拨号）→ 可选进详情只读 |

## 5. 状态矩阵

### 地图页

| 状态 | 表现 | 用户可做什么 |
| --- | --- | --- |
| loading | 顶栏或地图区轻提示「加载附近行程…」 | 等待 |
| empty | 无标记；短文案「附近暂无车找人」+ 可刷新 | 定位刷新 / 去发布人找车 |
| error | 「加载失败」+ 重试 | 重试 |
| marker selected | 底栏摘要出现 | 查看详情 / 关闭（点地图空白可收起） |
| driver restricted | 保持现有额度限制红条 | 不可搜乘客 |

### 详情页 · 乘客 · driver_trip

| 状态 | 表现 | 用户可做什么 |
| --- | --- | --- |
| loading | 「加载中…」 | 等待 |
| error | 失败文案 + 返回 | 返回地图 |
| default 未确认 | 摘要完整；**仅**「确认同行」；无可用拨号 | 确认 / 反馈入口可次要 |
| full / cannot accept | 确认禁用 + 原因（已满员/不可接） | 反馈 / 返回 |
| no passenger request | Toast 或条：「请先发布人找车」+ 可跳转发布 | 去发布 |
| confirmed | 展示已确认；**显示**「联系司机」 | 拨号 / 反馈 |
| call loading | 联系按钮 loading，防重复 | 等待 |
| call error | Toast：未绑定电话 / 未确认 / 网络 | 重试或检查 |

### 司机模式

| 状态 | 表现 |
| --- | --- |
| 任意 | 摘要与详情只读；**永不**出现拨号；页脚「司机端仅可查看，不可主动联系」 |

## 6. 交互说明

1. **点标记（乘客）**  
   - 不立刻整页跳转；先出 **TripSummarySheet**。  
   - 摘要字段（优先可读，勿主推 adcode）：  
     - 路线：`originName → destName`（可用 marker.title）  
     - 时间：`departStart` 格式化为本地「M月D日 HH:mm」起（有结束窗则「至 HH:mm」）  
     - 余座：`seats` / 详情 seatsLeft  
     - 分摊：`priceCents` → 「约 ¥x.xx / 人」；无价则不显示价行  
   - 主按钮文案：**「查看详情」**；次要可点卡片进入详情。

2. **查看详情**  
   - 进入现有 detail 路由；标题区同摘要字段，状态用中文（发布中/匹配中），不强调内部枚举英文。

3. **确认同行**  
   - 仅 `mode===passenger` 且 `type===driver_trip`。  
   - 点击后 loading；成功 → 本页切到 confirmed，**再出现**「联系司机」。  
   - 失败：Toast 具体原因（无需求单 / 满员 / 网络）。

4. **联系司机（拨号）**  
   - **仅 confirmed 后渲染或 enabled。**  
   - 确认前：**不渲染**拨号按钮（推荐），或 disabled + 文案「确认同行后可联系」——二选一，实现选「不渲染」以免误触。  
   - 成功取号后 `makePhoneCall`；失败不暴露内部堆栈。

5. **返回地图**  
   - 若已确认，再次进入同一行程详情应仍能联系（需回读 match 状态——实现/架构负责；UI 要求：刷新后仍显示可联系态）。

6. **关闭摘要**  
   - 再点同一标记切换或点地图空白收起 Sheet。

## 7. 文案要点

| 位置 | 文案 |
| --- | --- |
| 地图顶栏乘客 | 附近车找人 |
| 摘要空 | 附近暂无车找人，可稍后刷新 |
| 摘要主按钮 | 查看详情 |
| 确认按钮 | 确认同行 |
| 确认前说明 | 确认同行后可联系司机 |
| 联系按钮 | 联系司机 |
| 未发需求 | 请先发布人找车 |
| 满员 | 已满员，换一趟试试 |
| 司机页脚 | 司机端仅可查看，不可主动联系 |
| 拨号失败 | 暂时无法获取电话，请稍后重试 |

## 8. Tokens 使用

- 乘客主色：`color-brand` / `color-brand-soft`
- 地图司机标记：`color-map-driver`
- 危险/满员：`color-danger`
- 成功/已确认：`color-success`
- 卡片：`color-bg-card`、`radius-lg`、`space-md` / `space-lg`
- 次要字：`color-text-secondary`、`font-sm`

## 9. UI 验收（可观察）

- [ ] 乘客点司机标记：出现底栏摘要，含路线、时间、余座（有价含价格），**不是**以 adcode 为主文案。
- [ ] 摘要可进入详情；详情未确认前**看不到可用「联系司机」**。
- [ ] 确认成功后出现「联系司机」，点击走取号流程（失败有 Toast）。
- [ ] 满员/未发人找车有明确说明，确认按钮不可乱成功。
- [ ] 司机模式点标记无任何拨号入口。
