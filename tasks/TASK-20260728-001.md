# Task: 行程完成与互评

## Goal

乘客确认同行后，司乘**任一方**可将匹配单标记为「行程完成」；完成后双方各可互评一次（星级 + 可选文字）。

## Product decisions

- 任一方 complete → `COMPLETED`（不必双方都点）
- 评价仅本单参与者；重复评价友好错误
- 站内通知列表 UI Out

## Acceptance Criteria

- [x] CONFIRMED 匹配单参与者可「行程完成」→ COMPLETED
- [x] 非 CONFIRMED 不可完成（服务端 BadRequest 中文）
- [x] COMPLETED 后可评 1–5 星；重复评价 Conflict「您已评价过该行程」
- [x] 列表可读路线 + 中文状态 + 完成/评价入口
- [x] 服务端非参与者拒绝
- [x] deliver 绿；真机为人闸

## Implementation

### Backend

- `complete`：仅 CONFIRMED；已完成/取消有明确错误
- `myMatches`：附 `myReview` / `peerReview` / `reviewedByMe`
- `POST /reviews`：P2002 → 409 友好文案
- `GET /reviews/by-match/:matchOrderId`：参与者可读

### Mini-app

- `list`：匹配单卡片、行程完成、去评价/已评价
- `pages/review`：1–5 星 + 选填评语
- services：`completeMatch` / `submitReview` / `reviewsByMatch`
