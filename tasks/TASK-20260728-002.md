# Task: 司机认证提交与状态可见

## Goal

用户在小程序提交司机认证资料，并随时看到审核中 / 通过 / 驳回（含原因）；未通过时发车拦截并引导认证。

## Acceptance

- [x] 「我的」入口进入认证页，可查看状态
- [x] 未认证/驳回可提交；审核中/已通过不可重复提交
- [x] 驳回显示原因；通过显示已认证
- [x] 未通过时发布车找人引导/拦截（客户端 + 服务端）
- [x] 管理端原有审核仍可用
- [x] deliver 绿

## Implementation

### Backend

- `GET /driver-verifications/me` — status / canSubmit / canPublish / latest
- `POST /driver-verifications` — 姓名+车牌必填；PENDING/APPROVED 冲突
- `POST /driver-trips` — 仅 `verifyStatus=APPROVED` 可发

### Mini-app

- `pages/driver-verify` 表单 + 状态条
- 我的入口；发布页未认证黄条 + Modal
