## Goal

乘客在小程序地图上点选「车找人」司机标记后，能**清楚看到行程摘要**，并在**确认同行之后**才能获取并拨打司机电话；确认前不得暴露可拨号能力。

## Architecture (2026-07-28)

| Decision | Choice |
| --- | --- |
| 摘要数据源 | `GET /map/markers` 字段足够底栏；详情再拉 `GET /driver-trips/:id` |
| 确认后 matchId | 本页 state + `GET /matching/mine` 按 `driverTripId` 回读 `CONFIRMED\|COMPLETED`（仅 set 不 clear，避免列表延迟冲掉刚确认） |

| 区县顶栏 | 友好名主、adcode 次要 |

## Acceptance Criteria

- [x] 乘客模式、同区县有车找人标记时：点击标记可看到**可读行程摘要**（路线 title、时间、余座；有价展示分摊价）。主信息非裸 adcode。
- [x] 从摘要可进入完整详情；详情中「确认同行」仅乘客可见且可点（满员/不可接时禁用并说明）。
- [x] **确认前**：不渲染「联系司机」；文案「确认同行后可联系司机」；contact-phone 失败有 Toast。
- [x] **确认后**：出现「联系司机」；取号后 `makePhoneCall`（真机拨号为人闸，代码路径已接）。
- [x] 司机模式：摘要/详情无拨号；页脚只读提示。
- [x] 未发布人找车：Modal 引导去发布。
- [x] Loading / 空标记 / 请求失败有可见状态（地图 + 详情）。
- [x] 服务端强制：`users.service contactPhone` 仅乘客 + CONFIRMED/COMPLETED（代码审阅；未改后端鉴权）。
